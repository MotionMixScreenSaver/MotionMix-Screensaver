# MotionMix Screensaver

A lightweight Windows screensaver for mixing photos, animated GIFs and videos in one playlist.

MotionMix lets you create a custom Windows screensaver using your own media files without needing a background app running all the time.

## Features

- Mix images, animated GIFs and videos in one playlist
- Supports JPG, JPEG, PNG, WEBP, GIF and MP4
- Animated GIF playback
- MP4 videos play to completion
- Adjustable display time for images and GIFs
- Shuffle mode
- Drag and drop file import
- Drag and drop playlist reordering
- Fullscreen preview
- Exit on mouse movement
- Integrates with the classic Windows Screen Saver Settings
- Lightweight and free to use

## Installation

1. Download `MotionMixScreensaverSetup.exe` from the latest release.
2. Run the installer.
3. MotionMix will be installed and registered as a Windows screensaver.
4. Open **MotionMix Screensaver** to add your media and configure your playlist.
5. Click **Apply** when you are happy with your settings.

You can also access MotionMix from the classic Windows **Screen Saver Settings**.

## Windows SmartScreen

MotionMix is currently distributed as an unsigned installer.

Because of this, Windows SmartScreen may show an **Unknown publisher** or **Windows protected your PC** warning.

If this happens:

1. Click **More info**
2. Click **Run anyway**

The installer does not require administrator privileges.
